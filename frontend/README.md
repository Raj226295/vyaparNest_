# Frontend

React + Vite frontend for VyaparNest.

## Source layout

- `src/app/`: app shell and top-level composition
- `src/features/public-home/`: public landing page UI
- `src/features/user-panel/`: separate workspace for user panel screens and components
- `src/styles/`: shared global styles

## Commands

- `npm run dev`
- `npm run build`
- `npm run lint`
- `npm run preview`
